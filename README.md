# Blxckroze Agent

Blxckroze Agent is a personal AI agent you own outright. Name it, give it a soul, plug in your own Groq key, and it chats with you, remembers what matters, keeps your tasks, takes your notes, and browses the web for you. Everything it saves lives in your browser on your device. No account, no cloud landlord.

## Who this is for
Anyone who wants a personal AI that is actually theirs: your name on it, your rules, your data in a file you can export and carry anywhere.

## What it does
- Chat with a real tool using brain (bring your own Groq key: Llama 3.3 70B, GPT-OSS 120B, or Llama 3.1 8B)
- Browse for you: it searches the live web, opens pages, reads them, and answers with the links it used so you can check. Works with no extra key; an optional free Tavily key makes search stronger
- Act, not just talk: it calls tools to remember facts, search its memory, forget on request, add and finish tasks, and save and find notes
- Memory, Tasks, and Notes tabs where you can see, edit, and delete everything it saved
- A Soul editor and an About You page, so it talks your way and knows your world before you say a word
- Export and import: your whole agent is one JSON file you own

## Honest limits
It reads the web. It does not log into your accounts, click through checkouts, send email, or work while the page is closed. Hands, not just eyes, would need a self hosted companion worker. That is a later build, and this page will tell you the same thing if you ask it.

## Why pick it
- The app is one file, the key is yours, the memory is yours
- Nothing is uploaded anywhere. Close the page and your agent is exactly where you left it

## Price
Personal build, not for sale yet. The machine that builds one for anybody comes later.

## Get it
Open index.html in a browser. Add your free Groq key in Setup (console.groq.com) and start talking.
